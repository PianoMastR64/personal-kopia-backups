This is the information page for PianoMastR64's personal backup application. It uses Kopia and rclone to store and retrieve personal backups in the owner's Google Drive account.

What this application does

Kopia runs on the owner's computer. Rclone connects it to Google Drive so it can list, read, upload, update, and remove backup repository files as needed for backups, restores, and repository maintenance.

The Google OAuth client identifies this personal application during sign-in. The owner explicitly grants permission to access their Drive account. This setup is for the owner's own use and is not a public backup service.

About this website

This website explains the application and its data practices. It does not offer Google sign-in, connect to Google Drive, or accept backup uploads. Backup data and authorization tokens are not published here.
