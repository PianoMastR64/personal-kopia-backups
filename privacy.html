Privacy policy

Personal Kopia Backups is a personal application operated by PianoMastR64. It uses Kopia and rclone to back up and restore the owner's files through the owner's Google Drive account.

Google data access and use

With the owner's authorization, rclone uses the Google Drive API to access backup repository files and metadata, including file names, identifiers, sizes, and modification information. Operations include listing, reading, uploading, updating, and removing repository files for backups, restores, and maintenance.

The Drive permissions granted during authorization may allow access beyond the backup folder. This personal setup uses that access for the owner's backup operations. Google authorization tokens allow rclone to access Drive and renew access without requiring a sign-in for every backup.

Storage and protection

Backup repository data is stored in the owner's Google Drive account. Local configuration, authorization tokens, caches, and operational logs may be stored on the owner's computer. They are not included in this public website or its source repository.

Access to these local files and the Google account should be restricted to the owner. No passwords or authorization tokens should be submitted through this website or public GitHub issues.

Sharing and other uses

The application does not sell Google user data, use it for advertising, or use it to train AI models. Google processes the data involved in storing and accessing files through Google Drive. This setup does not intentionally disclose backup contents or authorization tokens to other people or unrelated services.

Retention, deletion, and revoking access

Backup data remains until the owner removes it through backup retention, repository maintenance, or deletion. Local configuration and cached data remain until the owner removes them.

The owner can revoke the application's authorization through Google Account connections. Revoking authorization stops future authorized access; it does not itself delete existing backup files or local configuration.

Website visitors

This static information website has no application analytics, advertising, forms, or Google sign-in, and sets no application cookies. It does not access visitors' Google Drive accounts. GitHub Pages hosts the website and may process technical request information, such as IP addresses, under the GitHub Privacy Statement.

Contact and changes

Questions can be submitted through the public GitHub issue tracker. Do not include private data. This page will be updated if the application's data practices change.
